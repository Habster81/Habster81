## 🚀 Software Projects


### 🎥 Tally Bridge

**Connecting Video Switchers and Cameras**

Free Windows 11 tally integration software supporting ATEM, TriCaster, TSL 3.1/5 and Sony, Canon and Panasonic camera protocols.

Features up to 16 mixer inputs, camera mapping, diagnostics and optional multi-PC coordination with Standby and Relay modes.

📂 **[GitHub Project](https://github.com/Habster81/tally-bridge)**

⬇️ **[Download & Documentation](https://www.habster.ch/tally-bridge-die-verbindung-zwischen-videomischer-und-kameras/)**
  

### 🎥 NDI Signal Stabilizer

**Stable resolution. Reliable NDI signals.**

NDI Signal Stabilizer is a free Windows application that maintains a constant output resolution and frame rate for NDI video streams, even when the incoming video format changes dynamically.

**Key Features:**
- Up to 5 independent NDI channels
- Fixed output resolution (720p / 1080p)
- Selectable output frame rates
- GPU and CPU processing
- Optional stereo audio
- Ideal for broadcast, live production and professional AV installations

📂 **[View GitHub Project](https://github.com/Habster81/ndi-signal-stabilizer)**

⬇️ **[Download from Official Website](https://www.habster.ch/ndi-signal-stabilizer/)**
